# ArriendoSeguro

Repositorio del emprendimiento **ArriendoSeguro** (formalización y trazabilidad de arriendos de vivienda en Colombia, con énfasis en privacidad y reglas de negocio alineadas a Ley 820, datos personales y mensajes de datos).

- **Código de la app:** carpeta `web/` (Next.js + TypeScript; ver [web/README.md](web/README.md)).
- **Entregables académicos / negocio:** en la raíz, archivos `Pasos del PUV- ArriendoSeguro.docx` e `Instrucciones-ArriendoSeguro.docx` (contenido de referencia del alcance, PUV y hoja de ruta operativa).
- **Remoto sugerido:** [github.com/clopezci/ArriendoSEguro](https://github.com/clopezci/ArriendoSEguro) (haz el primer `push` desde tu PC; el repositorio puede estar vacío al inicio).

## Arranque rápido

1. Abre la carpeta `web` y sigue [web/README.md](web/README.md) (`npm install`, `npm run dev`).
2. **Producción:** [https://arriendoseguro.vercel.app/](https://arriendoseguro.vercel.app/) — Vercel con **Root Directory = `web`**, cuenta `clpezci@gmail.com`. Detalle en [web/docs/checklist-firebase-vercel-operacion.md](web/docs/checklist-firebase-vercel-operacion.md) (§0).
